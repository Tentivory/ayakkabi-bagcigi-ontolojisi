# Ayakkabı Bağcığı Ontolojisi

## Resmî Bildiri

Bu depo, insanlığın en çok ihmal edilen metafizik nesnesini — yani **ayakkabı bağcığını** — bilimsel, hukuki ve varoluşsal düzlemde inceler.

Bağcık yalnızca bir ip değildir. Bağcık, düzen ile kaos arasındaki ince protokoldür. Çözülürse düşersiniz. Sıkı bağlanırsa kan dolaşmaz. Tam ortasında durmak ise bir tür sivil itaatsizliktir.

## Kuruluş Amacı

1. Bağcığın ontolojik statüsünü netleştirmek.
2. Düğüm atma eylemini bir tören olarak kodlamak.
3. Rastgele üretilen tezlerle insanlığı rahatsız etmek.
4. Çalışan bir Python scripti sunmak ki kimse “kod yok” demesin.

## Kurulum

```bash
python3 bagcik.py
```

Bağımlılık yoktur. Standart kütüphane yeter. Evren yeterince karmaşık.

## Kullanım

Program çalıştığında:
- size resmi bir bağcık tezi sunar
- düğüm sıkılığını ölçer (uydurma birim: Newton-Varoluş)
- bazen durup düşünmenizi ister

## Uyarı

Bu yazılım tıbbi tavsiye değildir. Ayakkabınızı bağlamadan yola çıkarsanız düşebilirsiniz. Düşmek de bir tür felsefedir ama o ayrı repo.
